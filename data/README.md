# Data folder

Place the official COMP20008 Assignment 2 Melbourne Inside Airbnb file here as:

```text
data/listings.csv
```

Do not substitute another download/version without recording it, because row counts, missingness, thresholds, correlations and model results must stay consistent across the project.

The notebooks look for both `data/listings.csv` and `../data/listings.csv` so they can be run from the repository root or from the `notebooks/` directory.

Recommended outputs after preprocessing:

```text
data/processed_listings.csv
data/split_assignments.csv
```

Do not commit unrelated personal files or API keys.
